🛡️ GUARDS DISPONIBLES
═══════════════════════════════════════════════════════════════════════════════

AuthGuard
  → Verifica JWT válido
  → Extrae datos del usuario
  → Obligatorio para cualquier ruta protegida

RolesGuard
  → Verifica rol específico
  → Usa @Roles(Role.ADMIN)
  → Comparación exacta del enum

PermissionsGuard
  → Verifica permisos granulares
  → Usa @RequirePermissions('permiso.slug')
  → Soporta múltiples permisos (OR)


🎀 DECORATORS DISPONIBLES
═══════════════════════════════════════════════════════════════════════════════

@Roles(Role.ADMIN, Role.TECH)
  → Protege por rol
  → Usuario debe tener UNO de los roles
  → Ejemplo: @Roles(Role.ADMIN)

@RequirePermissions('orders.create', 'orders.update')
  → Protege por permiso
  → Usuario debe tener UNO de los permisos
  → Ejemplo: @RequirePermissions('orders.create')

💻 CÓDIGOS DE EJEMPLO
═══════════════════════════════════════════════════════════════════════════════

PROTEGER POR ROL:
  ┌─────────────────────────────────────────────────────┐
  │ @Get('admin')                                       │
  │ @UseGuards(AuthGuard, RolesGuard)                   │
  │ @Roles(Role.ADMIN)                                  │
  │ getAdmin() {                                        │
  │   return 'Solo admin';                              │
  │ }                                                   │
  └─────────────────────────────────────────────────────┘

PROTEGER POR PERMISO:
  ┌─────────────────────────────────────────────────────┐
  │ @Post()                                             │
  │ @UseGuards(AuthGuard, PermissionsGuard)             │
  │ @RequirePermissions('orders.create')                │
  │ createOrder(@Body() dto: CreateOrderDto) {          │
  │   return this.ordersService.create(dto);            │
  │ }                                                   │
  └─────────────────────────────────────────────────────┘

MÚLTIPLES PERMISOS:
  ┌─────────────────────────────────────────────────────┐
  │ @RequirePermissions(['orders.update',               │
  │                       'orders.admin-update'])       │
  │ updateOrder() { }                                   │
  │ // Usuario necesita ALGUNO de estos permisos        │
  └─────────────────────────────────────────────────────┘

🆘 SOPORTE Y TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

ERROR 403 Forbidden:
  → Ver: GUIA_RAPIDA_INICIO.md (Sección de problemas)
  → Verificar: usuario tiene rol asignado
  → Revisar: rol tiene permiso requerido

RolService not found:
  → Verificar: RolModule importado en app.module.ts
  → Solución: Ya debe estar importado, verificar no hay typos

Seeder falla:
  → Verificar: BD está corriendo
  → Revisar: credenciales en .env
  → Comprobar: BD accesible

No reconoce @Roles:
  → Verificar: AuthGuard y RolesGuard en @UseGuards
  → Revisar: decorador importado correctamente

Para más ayuda → Leer: src/EJEMPLOS_ROLES_PERMISOS.ts
